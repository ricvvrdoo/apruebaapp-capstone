# Artefactos Scrum

El proyecto se gestiona con Scrum, en sprints de dos semanas alineados al calendario
académico (semestre del 10 de agosto al 12 de diciembre de 2026).

| Artefacto | Contenido |
|---|---|
| [Visión del producto](product-vision.md) | Para quién es Aprueba, qué problema resuelve y cómo se mide el éxito del proyecto |
| [Product Backlog](product-backlog.md) | Historias de usuario y técnicas priorizadas, con criterios de aceptación y estado |
| [Sprint Backlog](sprint-backlog.md) | Objetivo, elementos y resultado de cada sprint |
| [Definition of Done](definition-of-done.md) | Condiciones para considerar terminado un elemento del backlog |
| [Retrospectivas](retrospectivas.md) | Registro de retrospectivas y plantilla para las siguientes |

## Cómo se mantienen

- Los artefactos se actualizan al inicio (Sprint Planning) y al cierre (Sprint Review
  y Retrospective) de cada sprint, mediante un Pull Request con prefijo `docs/`.
- Los artefactos se crearon el 23-10-2026, durante el Sprint 3. La información de los
  sprints 0 a 2 se reconstruyó a partir del historial de Pull Requests del
  repositorio, y así se indica en cada caso.
